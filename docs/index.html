nni

YnniOS and SGnniOS: two busybox distros named after a toy chicken that keymashed a keyboard.

Download

Looking for the latest ISOs...

Write an ISO to a USB stick with dd or put it on a Ventoy stick. Secure Boot must be off. Installing is hard on purpose: the handbook command on the live system explains how.

Check that the download is genuine 
wget BASEsums BASEsig KEY
gpg --no-default-keyring --keyring ./nni-archive-keyring.gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS

The first command shows "Good signature from nni apt repository"; the second prints OK next to your ISO.

The family

YnniOS

Debian underneath, busybox as init, no systemd. Minimal for servers and homelabs, full with the NiWM desktop. Packages through pol.

SGnniOS

Source-Genius: Gentoo underneath, compiled on your machine through spol. Chickens instead of penguins at boot.

Shared core

nni settings in one file, the svc service manager, one-command wifi, desktop themes with nni theme, the boot splash and the handbook.

NiWM

The family's window manager and the YnniOS full desktop: tiling and floating, nine tags per monitor, a drop-down scratchpad and window swallowing, in well under 1 MB of memory. With nibar, a vertical taskbar with an apps menu and a tray.

NiWM

A window manager in the spirit of awesome, without Lua or a widget toolkit. Every setting is a command: put it in ~/.config/niwm/niwmrc, bind it to a key, or send it live with niwmctl. It works on any X11 system, not only on the nni family.

pol install niwm                 # YnniOS, with the repository below
spol install x11-wm/niwm         # SGnniOS, with the overlay below
echo 'exec niwm-x11' >> ~/.xinitrc
man niwm                         # keys, settings, nibar, monitors

On SGnniOS, allow the testing keyword first: echo 'x11-wm/niwm ~amd64' >> /etc/portage/package.accept_keywords/sgnnios

Add the YnniOS package repository

New YnniOS ISOs already have it. On an older install, run as root:

pol update && pol install ca-certificates
wget -O /usr/share/keyrings/nni-archive-keyring.gpg BASE/apt/nni-archive-keyring.gpg
wget -O /etc/apt/sources.list.d/nni.sources BASE/apt/nni.sources
pol update && pol install nni-base

Add the SGnniOS overlay

spol install dev-vcs/git
printf '[nni]\nlocation = /var/db/repos/nni\nsync-type = git\nsync-uri = REPO.git\nsync-depth = 1\n' \
  > /etc/portage/repos.conf/nni.conf
emerge --sync nni && spol install app-misc/nni-base
